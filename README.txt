TUGAS AKHIR DICODING - AFRIZA FEBY WIBOWO

Tema:
GIS: Alat, Sistem, atau Ilmu? Menghubungkan GIS dengan GIScience.

Kriteria utama:
- index.html memuat header, nav, main, article, aside, dan footer.
- Elemen nav memiliki anchor menuju profil Dicoding pribadi.
- Foto profil berada di dalam aside.
- Layout utama menggunakan CSS Flexbox.
- CSS dipisahkan ke styles/style.css.
- Terdapat media query untuk responsivitas.
- Semua gambar memiliki alt text.
- Tidak menggunakan Bootstrap, Tailwind, atau framework layout lainnya.
